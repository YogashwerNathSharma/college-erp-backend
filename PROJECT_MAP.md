## 3. Change-impact hint

- Editing a `*.service.ts` -> check its `*.controller.ts` and `*.routes.ts` in the same module.
- Editing `app.ts` mounts -> affects ALL routes under that base path.
- Editing shared middleware (`src/middleware/*`) -> affects every route that uses it.
